# Tipos de Issues

Escolha o tipo que melhor descreve o que você precisa. Isso ajuda a equipe a priorizar e responder mais rápido.

## Bug

Use quando algo no sistema não funciona como deveria.

Alguns exemplos são botão que não responde, horário exibido errado, sugestão que não aparece no fórum, contagem de alunos atendidos incorreta, etc.

[Ver todos os bugs reportados](https://github.com/MatheusSilver/Kairos/issues?q=is%3Aissue+label%3ABug)

## Erro Crítico

Use quando a página trava, fica em branco, o navegador para de responder ou a API retorna erro 500, exigindo recarregar ou reiniciar.

[Ver todos os erros críticos reportados](https://github.com/MatheusSilver/Kairos/issues?q=is%3Aissue+label%3A%22Erro+cr%C3%ADtico%22)

## Qualidade de Código

Use para reportar qualquer fluxo de código que esteja confuso ou complexo demais, discordância com boas práticas ou melhorias gerais de código que não alterem sua funcionalidade.

[Ver todas as issues de qualidade de código](https://github.com/MatheusSilver/Kairos/issues?q=is%3Aissue+label%3A%22Qualidade+de+c%C3%B3digo%22)

## Performance

Use quando o sistema apresenta lentidão, carregamento demorado da grade de horários, consumo excessivo de memória no navegador ou quando o otimizador demora demais para retornar uma solução.

[Ver todos os problemas de performance](https://github.com/MatheusSilver/Kairos/issues?q=is%3Aissue+label%3APerformance)

## Interface

Use para problemas visuais como elementos desalinhados, textos cortados, cores ou contraste inadequados na grade de horários, ou fluxos confusos de navegação.

[Ver todos os problemas relacionados a Interface](https://github.com/MatheusSilver/Kairos/issues?q=is%3Aissue+label%3AInterface)

## Documentação

Use para reportar erros, informações desatualizadas, falta de clareza ou ausência de documentação necessária em qualquer lugar do repositório.

[Ver todas as issues de documentação](https://github.com/MatheusSilver/Kairos/issues?q=is%3Aissue+label%3ADocumenta%C3%A7%C3%A3o)

## Otimizador

Use para problemas específicos da geração de horários, como solução inviável, restrição desrespeitada, resultado que atende menos alunos do que uma alternativa óbvia ou modelagem que precisa ser revista.

[Ver todas as issues do otimizador](https://github.com/MatheusSilver/Kairos/issues?q=is%3Aissue+label%3AOtimizador)

## Nova funcionalidade

Use para propor funcionalidades completamente novas que ainda não existem no sistema.

[Ver todas as funcionalidades solicitadas](https://github.com/MatheusSilver/Kairos/issues?q=is%3Aissue+label%3ADemanda)

## Tarefa

Use para registrar trabalho comum planejado pela equipe, como ajustes, refatorações, configuração de infraestrutura ou qualquer atividade que não se encaixe nos tipos acima.

[Ver todas as tarefas](https://github.com/MatheusSilver/Kairos/issues?q=is%3Aissue+label%3ADemanda)
