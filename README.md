# Kairos - Um software auxiliar à organização de horários semestrais

O Kairos nasce de uma característica do BCC, a possibilidade de professores e alunos decidirem juntos os horários de oferecimento das disciplinas. Essa abertura traz desafios que hoje são resolvidos à mão, em planilhas, como atender ao máximo de pessoas, garantir que alunos mais tímidos também participem e conectar as escolhas do semestre aos planos de longo prazo de cada aluno.

O sistema foi pensado com foco nos pontos abaixo.

- Coletar as disciplinas que cada aluno pretende cursar no semestre
- Registrar as janelas de horário de alunos e docentes, separando o desejável do possível
- Resolver o problema de otimização de horários atendendo o maior número de alunos sem inviabilizar os docentes
- Expor o impacto de cada sugestão em número de conflitos e alunos atendidos
- Substituir os comentários em planilha por um fórum de discussão integrado à grade

O projeto é uma ferramenta à parte das já existentes no IME, mas sua estrutura é mantida flexível o suficiente para uma futura integração com a plataforma **Aurora**.
